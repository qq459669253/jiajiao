# 初二上数学：全等三角形摸底与家教材料

适用：初二上，已学习全等三角形。课堂总时长120分钟；摸底卷8题、60分，建议40分钟。

## 课堂使用

| 环节 | 时间 |
| --- | --- |
| 说明规则 | 5分钟 |
| 独立摸底 | 40分钟 |
| 批改并询问思路 | 10分钟 |
| 针对主要问题讲解 | 42分钟 |
| 独立回练与核对 | 18分钟 |
| 复述方法、总结 | 5分钟 |

学生先拿摸底卷；教师答案分开发放。回练根据当堂问题选做2—3题。

重点知识：全等的对应关系与判定、垂直平分线、角平分线与垂直距离、面积周长转化、旋转全等、中点辅助线、动点线段关系。
